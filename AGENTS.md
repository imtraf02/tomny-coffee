# Tomny Coffee - Agent Guidelines

## UI Component Library & Standards

- **Component Library**: `@base-ui/react` (Base UI v1)
- **Documentation Index**: [https://base-ui.com/llms.txt](https://base-ui.com/llms.txt)
- **Component Docs**: For any Base UI component, read its markdown docs directly at `https://base-ui.com/react/components/<component-name>.md`
- **Location**: Store all reusable UI components in `apps/web/src/components/ui/`
- **Class Merging**: Always use `import { cn } from "@/lib/utils"`
- **Styling**: Tailwind CSS v4 and project design tokens in `apps/web/src/styles.css`
